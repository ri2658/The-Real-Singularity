Leaving a hilltop

The S-shaped state of the Allen–Cahn equation is a balance point, like a ball resting on a hilltop. Push it by a tiny amount ε and it eventually rolls off toward the stable hump. Theory says each tenfold smaller push buys the same extra waiting time: 1.5056 time units. Pick a push, run it, and see where the point lands.

Why 1.5056? Near S, a push grows like ε·eλ₁t, where λ₁ ≈ 1.5294 is the one unstable growth rate of the S state. The curve counts as "escaped" once it is 0.1 away from S, so the escape time is about ln(0.1/ε)/λ₁. Making ε ten times smaller adds ln(10)/λ₁ ≈ 1.5056. The simulator is plain forward Euler; it never sees this formula, yet its points fall on the line.
